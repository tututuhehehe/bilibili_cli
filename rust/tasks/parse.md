## 关键语义与坑
- `parse_target` 失败路径走 `die()`（SystemExit，退出码 2）——**单元录制覆盖不了**
  （实测会把录制进程杀掉）。基线只录成功路径。port 把失败路径写成 `Err` 返回，
  在「已知差异」注明；完整文案由 app 层用例（`bcli list 垃圾串`）验证，已在协调者
  的 app-cases 计划里。
  - 注意 `search.bilibili.com` 链接有**专属报错文案**，判断先于其他。
- `fmt_dur` 负数/小数：Python floor（divmod）——基线录了 `-5` 与 `4124.5`，
  用 euclid 语义对齐。
- `iso` 时区读源码确认（应为 +08:00 固定）；跨年/闰年/负时间戳基线已录
  （`-1`、`951782400`、`4102444800`）。
- `safe_name`：正则替换 + 截断 80；regex 陷阱（中文/emoji/全角）工具已自动加，
  确认 diff 全绿。
- `_qn_value`：纯数字串直转 int；未知名 → 127；None → 127。

## 基线已录，你要补：
1. `parse_target`：带单双引号的 BV、`?` 后缀链接、大小写混合 BV、`aid=170001`、

4. `iso`：2038 边界（2147483647）、极大值（2^62）。
